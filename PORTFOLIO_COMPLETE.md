```

- Dark background:    bg-gray-900, bg-gray-800
- Text:               text-white, text-gray-300
- Accent:             bg-blue-600 (buttons)

To change, find & replace bg-blue-600 with:
- bg-purple-600 (purple)
- bg-green-600 (green)
- bg-pink-600 (pink)
```

### Change Particles
```
In theme.js:
- particleCount = 80  (change number)
- background: #2563eb (change color - hex code)
```

## 📞 SUPPORT & TROUBLESHOOTING

### If particles don't show:
```
1. Hard refresh: Ctrl+F5
2. Check theme.js in root
3. Check console (F12) for errors
4. Clear browser cache
```

### If contact form doesn't work:
```
1. Check email in contact.php
2. Verify PHP mail() is enabled (hosting)
3. Check spam folder
4. Test with diagnostic page
```

### If pages don't load:
```
1. Check all files uploaded to public_html
2. Check file permissions (644 files, 755 folders)
3. Verify .htaccess is correct
4. Check hosting error logs
```

### If theme doesn't toggle:
```
1. Check theme.js loaded (F12 Network tab)
2. Check browser console for errors
3. Hard refresh: Ctrl+F5
4. Clear browser data
```
